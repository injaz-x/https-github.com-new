# تفعيل إرسال كود استرجاع كلمة المرور (مرة واحدة)

1. أنشئ حساباً مجانياً في Brevo (300 رسالة/يوم) ثم أضف بريدك مُرسِلاً موثّقاً (Senders & IP).
2. أنشئ مفتاح API من Brevo (SMTP & API ← API Keys).
3. في Supabase: Edge Functions ← New function باسم `recover` والصق محتوى `index.ts`، وأوقف خيار Enforce JWT إن لم تُرسل الواجهة مفتاح anon (هي ترسله، فالأفضل تركه مفعّلاً).
4. Edge Functions ← Secrets: أضف `BREVO_API_KEY` و `MAIL_FROM` (البريد الموثّق).
5. جرّب: شاشة الدخول ← «نسيت كلمة المرور؟».

الحماية: ردّ موحّد دائماً (لا يكشف وجود الحساب)، حدّ 5 رسائل/ساعة ودقيقة بين كل رسالة، والكود لا يُعاد في الرد أبداً.
